# SOURCES canton_zh (accessed 2026-11-12; scripts: scripts/canton_zh_city_fetch.py, canton_zh_city_dl.py, canton_zh_build.py)
Canton base URL for files: https://www.web.statistik.zh.ch/ogd/daten/ressourcen/ (publisher: Statistisches Amt Kanton Zürich). City: Statistik Stadt Zürich, CKAN datastore API https://data.stadt-zuerich.ch/api/3/action/datastore_search (the direct CSV download redirects to the blocked host ckan-prod.zurich.datopian.com, so the datastore API was used).

- romanians_canton_zh_civil_population_by_year.csv: "Bevölkerungsbestand und -wachstum des Kantons Zürich nach Nationalität", file KTZH_00001143_00002169.xlsx (sheet Staaten, BFS code 8232), updated 04.02.2026. Zivilrechtliche Wohnbevölkerung (Hauptwohnsitz, 31.12.), Kantonale Bevölkerungserhebung; 2025 provisional. Years 2010-2025.
- romanians_zh_municipality_zemis_2016_2018.csv: "Ständige ausländische Wohnbevölkerung nach Staatsangehörigkeit (2016-2018)", KTZH_00000123_00001228/1229/1230.xlsx. Kanton + Gemeinde rows. Source SEM ZEMIS, 31.12. Small cells (<5 in 2016, <3 in 2017) suppressed. Note: the 2016 file totals (2986) are not comparable with the BFS permanent figure (2531); definition of 2016 file is not stated (2017/18 files: permits Ci, B, C, L>=12m, F>=12m).
- romanians_canton_zh_international_net_migration.csv: statistik.info 2015/09 "Struktur der Einwanderung hat sich verändert" (Bucher), KTZH_00000608_00001520.pdf, Tabelle 1 (net international migration, ständige ausländische Bevölkerung, ZEMIS). Only 2002, 2009, 2014, Jan-Oct 2015.
- romanians_city_zurich_by_year.csv: dataset bev_bestand_nationen_hist_jahr_od3482 (BEV348OD3482), 1894-2025 (sparse before 1993, annual 1993-2025). City of Zürich wirtschaftliche Wohnbevölkerung, foreign nationals, 31.12.
- romanians_city_zurich_by_year_sex.csv: od3485. by_quartier_year.csv: od3361 (34 Quartiere, 1993-2025). by_permit_sex_year.csv: od3371 (C / B / Übrige). births: od4010. naturalisations: od3600 (age 0-19, 20-39, 40-59, 60+ groups). marriages: od3305 (Romanian as partner 1 or 2; rows overlap if both Romanian). asylum_sector_monthly: od5236 (2018-2025).
- cantonal_crosscheck.csv: canton values above vs /home/user/Diaspora/data/_reference/bfs_romanians_canton_year_permit_sex.csv (canton Zürich, Ständige Wohnbevölkerung, all permits, both sexes, all ages).
- Catalogue helper zh_resource_catalog.tsv: list of resources of the canton OGD derived from usage-statistics file KTZH_00002522_00005043.csv (not itself data on Romanians).
